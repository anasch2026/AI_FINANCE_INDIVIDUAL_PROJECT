# Final capstone deliverables

Use the repository-root README.md as the current entry point. The official guidelines supersede the historical 4800-word and ten-minute briefings.

- manuscript.docx and manuscript.md: final short manuscript, with four tables and six figures.
- presentation.pptx: four-slide main defence; defence-script.md contains the spoken text.
- presentation-backup.pptx: rebuilt fifteen-slide backup, with presentation-outline.md.
- defence-qa.md: twenty-four preparation questions.
- results.csv, costs-robustness.csv, diagnostics/: frozen reported evidence.
- verification-report.json: numerical consistency and formal compliance checks.

Run `python -B reproduce.py` from the repository root to reconstruct saved-output documents without fitting or strategy execution. See the root README for the exact scope and limitations.
